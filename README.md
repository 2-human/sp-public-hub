# Protected page

This repository serves an **encrypted password gate only** (AES-256-GCM + PBKDF2-HMAC-SHA256, 600k iterations, decrypted in the browser via the Web Crypto API). The plaintext is never published here.

| File | Purpose |
|---|---|
| `index.html` | The encrypted gate (generated by `encrypt.py`; never edit by hand). |
| `encrypt.py` | Encrypts the private plaintext into `index.html`. |
| `.nojekyll` | Serve files as-is. |
